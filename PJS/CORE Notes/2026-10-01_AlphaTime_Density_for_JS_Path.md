# AlphaTime Density for the Jane Street Path

**Date:** 2026-10-01  
**System:** PJS

## Core idea

The Jane Street path is built by repeatedly spending time in high-quality states.

Not every hour needs to be work, but the overall system should compound toward:
- stronger technical ability;
- better judgment;
- stronger relationships;
- better health;
- durable artifacts;
- more career optionality.

## High-quality flow

**friend / mentor / peer**
→ conversation
→ insight
→ project
→ artifact
→ reputation
→ opportunity
→ stronger node.

This is the kind of flow PJS wants.

## Low-quality branch

Random nightlife, purposeless Kowloon / Causeway Bay detours, pornography or repeated masturbation become relevant only when they create:
- attention fragmentation;
- loss of intended work;
- next-day aftershock;
- weaker preparation;
- reduced energy for people and projects.

The rule is not moral prohibition.

The rule is:
> **Protect the capacity to enter the next high-quality node.**

## PJS operating filter

Before a detour, ask:
- Does it improve People?
- Knowledge?
- Health?
- Capital?
- Artifact?
- Opportunity?
- Intentional Recovery?

If not, skip by default.

## Long-run target

Jane Street is not a single interview event.

It is a multi-year compounding path requiring:
**energy + preparation + relationships + artifacts + consistency.**

Therefore:
**AlphaTime density > stimulation density.**
