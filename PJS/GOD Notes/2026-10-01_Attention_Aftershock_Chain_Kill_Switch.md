# Attention Aftershock & Chain Kill Switch — PJS

**Date:** 2026-10-01

## Jane Street path implication

The Jane Street path requires not only entering high-quality nodes, but also **closing low-quality branches quickly**.

Observed negative chain:

**HK Alpha mission → purposeless Mong Kok / Kowloon expansion → attention fragmentation → weak return / recovery close → next-day startup failure → immediate-reward loop → less preparation, less building, less outreach**

## Attention Aftershock

Low-quality movement can create delayed costs:
- poorer concentration after returning;
- weaker next-day launch;
- more stimulation-seeking;
- fewer artifacts produced;
- reduced capacity for applications / DD / coding / conversations.

Therefore the true cost of a detour is larger than its clock time.

## PJS Kill Switch

When the route loses purpose:

**STOP → CLOSE → RETURN → RECOVER → SET NEXT ACTION**

No “since we are already here” branches.

## HK default route

**Shenzhen → Lok Ma Chau → East Rail → Admiralty / Central → JS / quant / meeting / DD / hosting → Hong Kong Island Return Gateway → Shenzhen → recovery**

The route must support the next day, not consume it.

## Core rule

> **A high-quality node should improve access to the next high-quality node. A low-quality branch must be terminated before it propagates.**

This is part of Jane Street preparation because sustained high-quality work is a systems problem, not only an interview problem.
