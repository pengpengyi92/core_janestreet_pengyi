# High-Quality Node Compounding — PJS God Note

**Date:** 2026-10-01

## Principle

The path toward Jane Street is built by repeatedly entering higher-quality nodes.

A high-quality node contains some combination of:
- strong people;
- hard problems;
- rigorous systems;
- useful knowledge;
- real collaboration;
- durable artifacts;
- meaningful opportunity.

## Replace low-return flow with real flow

Do not spend Hong Kong ETM-AAO on purposeless nightlife or massage / 141-style detours.

The desired flow is:
**friends → partners → mentors → researchers → engineers → traders → teams → institutions → projects.**

Every trip should increase familiarity with the people and environments we actually want to belong to.

## Jane Street interpretation

Jane Street is not merely a company target. It is a benchmark for the quality of node we want to enter:
- exceptional peers;
- technical depth;
- strong engineering / trading culture;
- high-quality infrastructure;
- long-duration learning;
- opportunities to build things that matter.

The aim is:
**prepare → connect → enter → contribute → accumulate projects and judgment → compound for years.**

## ETM-AAO filter

Before a detour, ask whether it leaves:
**People / Knowledge / Health / Capital / Artifact / Opportunity.**

If not, and it is not intentional recovery, skip it.

## HK operating model

Use Hong Kong selectively:
**East Rail → Admiralty / Central → firm / person / meeting / DD / hosting → return.**

Do not confuse urban stimulation with progress.

> **The objective is not to visit more places. The objective is to spend more life inside high-quality nodes.**
